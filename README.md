# «Не спишут» (@nespishut_bot) — трекер подписок: Telegram-бот + мини-приложение

Первая версия (MVP): пользователь добавляет подписки в мини-приложении, бот напоминает
о списаниях заранее, показывает сумму в месяц/год и помогает отменить ненужное.

## Что уже работает

**Мини-приложение (Next.js)**
- Сводка: сколько уходит в месяц и в год, сколько спишут за 7 дней, траты по категориям.
- Список подписок, отсортированный по ближайшему списанию; пробные периоды помечены.
- Добавление в два касания из каталога (33 популярных сервиса, поиск с синонимами: «кп» → Кинопоиск).
- Своя подписка (спортзал, хостинг — что угодно).
- **Импорт выписки банка**: загружаешь PDF-выписку (Сбер, Т-Банк, Альфа, ВТБ…) или CSV из Т-Банка —
  приложение находит регулярные списания и предлагает добавить их галочками. Файл читается прямо на
  устройстве и на сервер не уходит. Сервисы из каталога узнаются даже по одному списанию, незнакомые —
  по повторам с одинаковой суммой раз в неделю/месяц/квартал/полгода/год. Давно не списывавшиеся
  помечаются «возможно, уже отменена», уже добавленные — «уже есть».
- Периоды: неделя / месяц / 3 месяца / полгода / год. Напоминание: в день списания, за 1/2/3 дня, за неделю.
- «Я отменил» → подписка уходит в архив, приложение показывает, сколько ты экономишь в месяц.
- **Пересечения**: «Кинопоиск уже входит в Яндекс Плюс», «Okko и Звук — в СберПрайм», «KION — в МТС Premium»,
  а также один сервис, добавленный дважды. Карточка «Можно сэкономить N ₽ в месяц» на главной, подсказка
  в карточке подписки, в напоминании перед списанием и при добавлении через бота. Список пакетов —
  `apps/api/src/subscriptions/bundles.ts`.
- **Общие подписки**: в карточке подписки «Пригласить участников» → ссылка t.me/бот?start=join_… уходит через
  «Переслать» Telegram. Цена делится поровну (вверх до рубля), в итогах «в месяц» у каждого — только своя доля.
  Владелец видит, кто перевёл за ближайшее списание, может отметить вручную или исключить; участник видит
  долю и кому переводить, может отметить перевод или выйти.
- Настройки: время напоминаний и часовой пояс (определяется автоматически по устройству).
- Тема Telegram (светлая/тёмная), системная кнопка «Назад», вибрация.

**Политика конфиденциальности** — `/privacy` (152-ФЗ). Оператор и контакт задаются в `apps/web/.env.local`:
`NEXT_PUBLIC_OPERATOR_NAME`, `NEXT_PUBLIC_SUPPORT_CONTACT`. Ссылка — в приветствии бота и в настройках приложения.

**Бот (grammY)**
- `/start`: короткое приветствие с кнопками «Найти подписки в выписке» (сразу открывает импорт), «Открыть приложение»,
  «Написать текстом», «Переслать СМС» и ссылкой на политику; кнопка «Подписки» в меню чата ставится автоматически.
- `/delete_me`: удалить все свои данные (с подтверждением); участники его общих подписок получают уведомление.
- `/list`: список подписок и итог в месяц/год.
- **Подписка текстом**: «Okko 399 15 числа», «Netflix 999 в год 20 ноября», «пробный Кинопоиск 299 до 05.12» —
  бот разберёт и предложит добавить кнопкой.
- **Пересланное СМС/пуш банка** о списании («Покупка 449 ₽ YANDEX*PLUS…»): бот узнаёт сервис и сумму.
  Если подписка уже есть и цена другая — сообщает, что она подорожала (и на сколько в год), и предлагает обновить.
- Напоминания с кнопками **«✅ Оставляю» / «❌ Отменил» / «📖 Как отменить» / «↩️ Я передумал»**.
- Отдельный текст для пробных периодов: «заканчивается завтра, спишут 299 ₽».
- **Общие подписки**: приглашение с кнопкой «Присоединиться»; перед списанием участникам, которые ещё не
  перевели, — «Твоя доля 150 ₽, кому перевести: …» с кнопкой «✅ Перевёл»; владельцу — уведомления
  о новых участниках и переводах, а в его напоминании — «скинулись 1 из 2».
- **Проверка пользования**: раз в неделю бот спрашивает про одну подписку «Ты пользовался Okko в последний
  месяц? Это 4 788 ₽ в год» → «Пользуюсь» / «Нет» (подскажет, как отменить) / «Не спрашивай про неё».
  Начинает с самых дорогих; про одну подписку — не чаще раза в 2 месяца; не трогает пробные, свежие и те,
  у которых списание через 1–3 дня. Выключается в настройках.

**Для владельца бота** (Telegram ID в `ADMIN_TELEGRAM_IDS` в `apps/api/.env`)
- `/stats` — админ-панель в одном сообщении, разделы кнопками: обзор (рост к прошлой неделе),
  люди (новые, заходившие за день/неделю/месяц, с подписками, распределение), рост по дням за 2 недели,
  подписки (откуда добавляют: приложение / выписка / текст / СМС, категории, периоды, общие),
  сервисы (популярные, **свои подписки, которых нет в каталоге**, чаще отменяемые), деньги, активность бота,
  последние новые пользователи. Команда видна в меню только админам, остальным `/stats` отвечает справкой.
- Сообщения об ошибках в Telegram: падения бота, рассылки напоминаний и ошибки 500 в API
  (одинаковые — не чаще раза в 10 минут).

**Логика**
- Подпись Telegram (initData) проверяется на сервере, так что чужие подписки не прочитать.
- Даты считаются по часовому поясу пользователя: «завтра» в Новосибирске и в Москве — разные дни.
- Прошедшие даты списаний переносятся на следующий период автоматически. 31-е число не «съезжает» на 28-е после февраля.
- Одно напоминание на одну дату списания: дубли не уйдут, даже если запустить два экземпляра сервера.
- Не пишет ночью (после 22:00), при сетевой ошибке повторит попытку. Если пользователь заблокировал бота, напоминания ему не шлются.
- Если у сервиса в каталоге нет цены, подсказывается средняя цена, которую вводят сами пользователи.

## Стек

| Часть | Технологии |
|---|---|
| API и бот | NestJS 11, Drizzle ORM, PostgreSQL, grammY, @nestjs/schedule |
| Мини-приложение | Next.js 16, React 19, TypeScript, pdf.js (чтение выписок) |
| Тесты | API (Jest): 72 теста на даты, деньги, подпись Telegram, напоминания и тексты бота. Мини-приложение (Vitest): 15 тестов на разбор выписок |

Почему Drizzle, а не Prisma: в Drizzle нет бинарного движка, только TypeScript. Он проще
деплоится на VPS, схема лежит в одном файле `apps/api/src/db/schema.ts`, а запросы типизированы так же.

## Структура

```
subs-tracker/
├── apps/api/                 # NestJS: REST API + Telegram-бот + планировщик напоминаний
│   ├── drizzle/              # SQL-миграции (генерируются из schema.ts)
│   └── src/
│       ├── db/               # schema.ts, catalog.data.ts (каталог сервисов), migrate.ts, seed.ts
│       ├── auth/             # проверка initData Telegram, guard
│       ├── subscriptions/    # CRUD подписок, статистика
│       ├── catalog/          # поиск по каталогу
│       ├── bot/              # бот и все его тексты (messages.ts)
│       ├── reminders/        # cron раз в 10 минут: кому и когда напомнить
│       └── common/           # даты и деньги
└── apps/web/                 # Next.js: мини-приложение (/app) и лендинг (/)
    └── lib/statement/        # импорт выписки: extract.ts (PDF/CSV → строки), parse.ts (поиск подписок)
```

## Запуск на Windows (локально)

Нужны Node.js 20+ и PostgreSQL (обычная установка, Docker не нужен).

**1. База данных** (в PowerShell):
```powershell
psql -U postgres -c "CREATE DATABASE subs;"
```

**2. API** — первое окно PowerShell:
```powershell
cd apps\api
copy .env.example .env      # открой .env и впиши пароль от PostgreSQL в DATABASE_URL
npm install
npm run db:migrate          # создать таблицы
npm run db:seed             # заполнить каталог сервисов
npm run dev
```

**3. Мини-приложение** — второе окно:
```powershell
cd apps\web
npm install
npm run dev
```

Открой **http://localhost:3000/app**. Пока в `.env` задан `DEV_TELEGRAM_ID`, приложение работает
в обычном браузере без Telegram, и можно спокойно верстать и тестировать.

Тесты: `cd apps\api` → `npm test` и `cd apps\web` → `npm test`.

## Подключить настоящего бота

1. В Telegram открой **@BotFather** → `/newbot` → получи токен.
2. Впиши токен в `apps/api/.env` → `BOT_TOKEN=...` и перезапусти API. Бот начнёт отвечать на `/start` и `/list`.
   Если Telegram на компьютере открывается только через VPN, укажи прокси VPN-клиента:
   `TELEGRAM_PROXY=socks5://127.0.0.1:10808` (порт SOCKS у Happ/v2rayN). Тогда бот работает и без системного VPN.
3. Чтобы мини-приложение открывалось внутри Telegram, нужен **публичный HTTPS-адрес**:
   Telegram не открывает `http://localhost`. Варианты:
   - сразу задеплоить на VPS (см. ниже) — надёжнее всего;
   - для быстрой проверки — HTTPS-туннель к `localhost:3000` (например, `cloudflared tunnel --url http://localhost:3000`).
4. Впиши адрес в `WEBAPP_URL=https://твой-домен/app` и перезапусти API: бот сам поставит кнопку
   «Подписки» в меню чата.

## Деплой на VPS (Ubuntu + nginx)

```bash
# на сервере: Node.js 20+, PostgreSQL, nginx, pm2 (npm i -g pm2)
cd apps/api && npm ci && cp .env.example .env   # заполнить: DATABASE_URL, BOT_TOKEN, WEBAPP_URL
echo "NODE_ENV=production" >> .env              # отключает DEV_TELEGRAM_ID
npm run db:migrate && npm run db:seed && npm run build
pm2 start dist/main.js --name subs-api

cd ../web && npm ci && npm run build
pm2 start npm --name subs-web -- start
pm2 save && pm2 startup
```

nginx проксирует домен на Next.js (порт 3000). Next.js сам отправляет `/api/*` в NestJS (порт 4000),
поэтому наружу открыт только один порт:

```nginx
server {
    server_name subs.example.ru;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```
HTTPS: `sudo certbot --nginx -d subs.example.ru`.

Порт 4000 наружу не открывай: API должен быть доступен только через Next.js.

## Что заполнить перед запуском

- **Цены в каталоге** (`apps/api/src/db/catalog.data.ts`, поле `price`). Я оставил их пустыми специально:
  цены меняются по несколько раз в год, а неверная цена хуже пустого поля. Впиши актуальные хотя бы
  для популярных сервисов и запусти `npm run db:seed` ещё раз (подписки пользователей не затронутся).
- **Названия в выписках** (поле `merchants`): как сервис подписан в выписке банка, например
  `YANDEX*PLUS`. Если импорт не узнал сервис, который у тебя точно есть, — посмотри, как он записан
  в выписке, допиши сюда и запусти `npm run db:seed`.
- **Логотипы** лежат в `apps/web/public/logos/<slug>.png`. Для нового сервиса каталога впиши его сайт
  в `apps/web/scripts/fetch-logos.mjs` и запусти `node scripts/fetch-logos.mjs <slug>` из `apps/web`.
- **Инструкции «как отменить»** — `apps/api/src/db/cancel-guides.ts` (17 популярных сервисов, сверено в ноябре 2026).
  Показываются в боте (кнопка «📖 Как отменить» в напоминании), в карточке подписки в приложении и на SEO-страницах
  `/otmena` и `/otmena/<slug>` (разметка HowTo, `sitemap.xml`, `robots.txt`). Поправил текст — `npm run db:seed`.

## Изменение схемы БД

Правишь `apps/api/src/db/schema.ts` → `npm run db:generate` (создаст новую миграцию в `drizzle/`)
→ `npm run db:migrate`.
